# SPECTRA — Android field monitor

Scientific-minded environmental anomaly logging project for Samsung Galaxy S25 Ultra and compatible Android phones.

**Not a ghost detector.** No validated method exists to detect spirits. Sensor deviations have ordinary potential causes.

## v0.1
- Live 3-axis magnetometer readings in microtesla
- Magnitude, running mean and sample standard deviation
- Sensor availability and accuracy reporting
- Offline, no permissions required for magnetometer
- GitHub Actions debug APK build

## Install
Open **Actions → Android APK → latest successful run → SPECTRA-debug-apk**. Download ZIP, extract APK and install on your Android device.
